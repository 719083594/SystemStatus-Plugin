# SystemStatus-Plugin v3.0.1

本次更新插件本体，宿主机采集器代码和接口保持不变。

## 修复
- 图片生成成功但发送失败或返回错误结果时，降级为文字；不自动重发图片。
- 校验配置 JSON、HTTP 地址、等待时间和显示时区，配置错误仍回复可用的机器人报告。
- 校验宿主机响应的数据结构，异常 JSON 或缺失字段不会同时破坏图片和文字报告。
- 账号卡片区分在线、离线、连接断开、状态异常和状态未知，不再将协议连接等同于账号在线。
- 新增 TRSS 接入层回归测试，覆盖真实入口的图片降级、错误返回、配置错误和账号状态。

## 安装与更新
- 发布附件 `SystemStatus-Plugin-v3.0.1.zip` 是插件本体包，解压后只有 `SystemStatus-Plugin/` 顶层目录。
- 放入 TRSS 的 `plugins/SystemStatus-Plugin/`；不安装系统服务、定时任务或其他插件。
- 包内不含采集器、测试、实例配置和凭据。采集器安装材料仍在源码仓库的 `collector/`。
- 未接入宿主机数据时，服务器部分会提示不可用，机器人账号与插件部分仍能显示。
- 更新已有安装后需重启 TRSS 以刷新 `lib/` 模块缓存；QQ 客户端可保持登录。
- `SHA256SUMS.txt` 用于核对发布包完整性；开发测试应在完整源码仓库中执行。

## 验证边界
- 发布流水线只在同一提交的 Node 20/22/24/26 与现有 Python 单元测试通过后运行。
- 接入层测试使用模拟框架，不能替代实际 QQ 收发、权限及图片清晰度验证。
- 文字发送本身失败时记录错误并结束，不无限重试或重复发图。
