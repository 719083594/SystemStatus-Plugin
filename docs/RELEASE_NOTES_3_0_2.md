# SystemStatus-Plugin v3.0.2

本版发布 **插件 + 宿主机采集器完整包**。下载 `SystemStatus-Plugin-v3.0.2.zip` 后，`plugin/SystemStatus-Plugin/` 安装到 Yunzai，`collector/` 单独安装到 Linux 宿主机。两部分版本均为 3.0.2，安装位置与服务相互独立；下载解压不会自动部署。

- 采样失败时短暂保留上次成功数据，并在图片和文字中提示；快照达到 `max(60, 3 × refreshSeconds)` 秒后返回 503。健康检查反映无快照、采样失败和数据过期。
- Docker 各项查询分别容错，保留可读取数据，报告缺失项和容器列表截断，未知状态不显示成已停止。
- 修正 CPU guest/guest_nice 重复计数。
- 校验采样间隔、端口、环境变量名与内网监听地址；限制 HTTP 活跃连接数和空闲读取时间。
- README 区分源码目录、完整包目录和实际部署位置；保留 v3.0.1 的指令权限、配置校验、图片发送失败文字降级及账号状态判断。
- 打包使用明确清单，包含两部分代码、安装示例、服务单元、许可证、迁移及发布说明；不含 token、实例配置、测试、缓存或依赖目录，并提供 SHA-256。

验证范围：本地自动化及 GitHub Node 20/22/24/26 + Python 3.13 CI；故障注入为隔离测试。本版未升级新加坡或东京运行实例，真实 Linux/Docker/QQ 全流程仍需部署后验收。此前 v3.0.1 东京回图约 2 秒的结果不代替本版验收。

升级时保留现有 `.env`、采集器 `config.json` 及插件 `config/config.json`，分别更新程序文件并重启对应服务。详细步骤见 README；旧标签与发行资产不变。
